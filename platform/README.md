# Campus IQ — AI study platform

Notes, past papers, video lessons, quizzes, a revision planner and an AI tutor, powered by the **free Google Gemini API**.

## Features
- **Smart notes**: upload PDF / DOCX / TXT / photos (scans are OCR'd by Gemini) or paste text → summary, key points, flashcards.
- **Past papers**: questions are extracted and answered step by step.
- **Ask this note / AI tutor**: answers grounded in your material (math rendered with KaTeX).
- **Video lessons**: shared YouTube library with an AI companion explainer and watch tracking.
- **Rapid quizzes**: MCQs on a topic or any note; mistakes feed a weak-spot radar.
- **Revision planner**: day-by-day plan to your exam date that gives weak topics extra time.
- Karma, daily streak, shared/private uploads, search.


## What is inside
| Area | What users get |
|---|---|
| **Learning hubs** | DSA Mastery, Engineering Library (common + Computer, Electrical, Civil, Mechanical), **Nepal Engineering Licence (NEC) prep**, Job Preparation. Every topic has AI-written notes, practice questions, video links, a quiz and progress tracking. Timed mock tests per section. |
| **Resume maker** | 3 templates, live preview, AI summary / bullet rewriter / ATS match against a job post, export to PDF and Word. |
| **Presentation generator** | Any topic or any of your notes becomes a slide deck with speaker notes. Edit slides, pick a theme, download `.pptx`. |
| **Note summarizer** | Paste, upload (PDF, DOCX, TXT, photo) or pick a note. 7 styles, 6 languages, save to notes. |
| **Mock interview** | AI interviewer for any role with an honest scorecard. |
| **AI assistant** | Floating help guide + tutor on every page. |
| **Account** | Avatar menu with upload / remove avatar, dark mode, feedback, log out. |
| **Layout** | Sidebar on desktop, bottom navigation on phones, dark mode, installable (PWA manifest). |

AI content for the hubs is generated by Gemini on demand and cached, so there are no hardcoded lessons. NEC content is study help only: always confirm syllabus and laws with official Nepal Engineering Council notices.

### Editing the design
The compiled stylesheet `static/core/tailwind.css` is committed, so you do not need Node to run the app. To change styles: `cd iq/frontend && npm install && npm run build`.

## Run locally
```bash
cd iq
python -m venv .venv && source .venv/bin/activate     # Windows: .venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env        # then paste your free key from https://aistudio.google.com/apikey
python manage.py migrate
python manage.py createsuperuser   # optional
python manage.py runserver
```

## Deploy (e.g. Render)
Build: `pip install -r requirements.txt && python manage.py collectstatic --noinput && python manage.py migrate`
Start: `gunicorn iq.wsgi` (working dir `iq/`).
Set `DJANGO_DEBUG=false`, `DJANGO_SECRET_KEY`, `DJANGO_ALLOWED_HOSTS`, `DJANGO_CSRF_TRUSTED_ORIGINS`, `GEMINI_API_KEY`.
Uploaded files live on local disk; use a persistent disk (or object storage) in production. SQLite is fine for small deployments.

## Tests
`python manage.py test` (Gemini calls are mocked; no key needed).
