Turn on the AI (2 minutes)

Campus IQ uses Google's free Gemini API. You only need to paste a key into a file once.

{% if AI_ENABLED %}check_circle{% else %}error{% endif %}

{% if AI_ENABLED %}AI is ON. A Gemini key was found.{% else %}AI is OFF. The server can't see GEMINI_API_KEY yet.{% endif %}

  1. 1. Get a free key

    Open aistudio.google.com/apikey, sign in with Google, click Create API key and copy it (it starts with AIza).

  2. 2. Create the .env file

    In the project's iq folder (the one with manage.py), copy .env.example and name the copy exactly .env. On Windows make sure it isn't .env.txt (turn on "File name extensions" in File Explorer).

  3. 3. Paste the key

    GEMINI_API_KEY=AIzaSy...your_key_here

    No quotes, no spaces around the equals sign.

  4. 4. Restart the server

    Press Ctrl+C in the terminal, then run python manage.py runserver again. Reload this page: the status above should turn green.

Free-tier keys have per-minute and daily limits. If you see a "rate limit" message, wait a minute and retry.
